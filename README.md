## Using dotfiles
If you want to copy entire config clone this repository by running
```bash
git clone https://github.com/antste0/thinkpad-dotfiles.git
```
and then place each config file in its own specific folder. You **will** need to either place wallpapers in `~/Pictures/wallpapers/` or change the location in the config.

Alternatively you can download only some specific files.

## Fonts
I'm using **FontAwesome** for some of my configurations. This makes me able to display icons on the status bar.
